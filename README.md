# Учебник CalAI 📚

> **Интерактивный учебник по веб-разработке и созданию умного планера времени CalAI.**  
> Стек проекта: TypeScript, React 19, Next.js 16 (App Router), Supabase (PostgreSQL, RLS), Tailwind CSS 4, shadcn/ui и Google Gemini API.

🌐 **Читать онлайн:** [https://alexxxxids.github.io/calai-textbook/](https://alexxxxids.github.io/calai-textbook/)

---

## О проекте

Этот учебник написан в живом, неформальном стиле от лица сеньора-наставника **Митрича** и ведёт читателя от самых базовых понятий («что такое веб и HTTP») до архитектуры сложного продакшн-приложения с ИИ, фоновыми задачами, защитой RODO/GDPR и строгим тестированием.

Каждая глава содержит:
- **Теорию и ментальные модели** простыми словами без заумной «воды».
- **Интерактивные схемы Mermaid**, поясняющие потоки данных.
- **Разбор реальных грабель (TRAP)** из промышленной разработки.
- **Вопросы экзаменатора (Nauczyciel zapyta)** на польском языке с эталонными ответами для защиты проекта.
- **Интерактивные чек-листы задач**, прогресс по которым автоматически сохраняется прямо в вашем браузере.
- **Встроенный поиск** по всему тексту учебника.
